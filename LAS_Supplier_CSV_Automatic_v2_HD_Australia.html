AUTOMATIC V2 · HARDBACK + HD AUSTRALIA · FILL → SAVE → NEXT ORDER

Automatically fill, save and move to the next order

This version reads the product grid while ignoring nested specification tables, totals and layout rows. It opens each order, checks for existing supplier references, selects only the intended supplier’s items, sets In Production - (Confirmed), fills the reference and date, saves once, and verifies the saved values again after a fresh page load before moving to the next row automatically. Multiple items for the same supplier are selected together; you do not need to choose a status link for each item.

This bookmark saves automatically after you click Start automatic batch — SAVE. The previous review checkpoint remains available unchanged.

Skipped rows and manual choices

NOT FOUND, NOT_FOUND and NOT-FOUND in either the order number or supplier reference are skipped before opening the order. Clear LAS “order not found” responses are also skipped. If any item for the selected supplier already has a reference, that order/supplier row is skipped without opening an editor.

A missing supplier pauses for your selection. If a named supplier is absent from the order, choose its exact LAS name. Missing/invalid order details and conflicting duplicate CSV references also pause. Explicit CSV suppliers and inferred Huasheng suppliers take priority over the initial dropdown; a prompted correction applies to that row.

Pause stops automatic steps immediately. Continue rechecks the page and selected values. Stop ends the run. Skip current row never clicks Save, Cancel or an unlock control; cancel your own unsaved LAS editor first. Stop or Skip cannot undo a submitted Save.

If a Save response or reload cannot be verified, the batch pauses. The attempt is retained in the LAS tab’s session storage and Save is never retried automatically. Continue checks the existing attempt; skipping records SKIPPED_SAVE_UNVERIFIED. Keep the same LAS tab for recovery. Download results before closing the helper.

CSV formats

The Hardback lookup export can be uploaded directly: LAS Order, Supplier Ref, Customer, Supplier. Unresolved lookup markers (AMBIGUOUS, REVIEW, PENDING, SEARCHING and STOPPED) are skipped without opening or saving the order.

Use LAS order, Supplier reference, Customer, Supplier, Despatch; or Order Ref, Supplier Ref, Customer Name, Despatch; or Customer Reference Order Number, Supplier Ref Order Number, Customer Name, Supplier. Sales Order Number and Huasheng Order Number identify the Victory supplier sheet. Extra Victory columns, multiline headers, quoted commas and leading zeros are supported. Despatch, ordering and shipment dates do not change LAS’s scheduled dispatch date or the confirmation date you choose.

Empty trailing columns are ignored only when their values are empty. NOT FOUND in Despatch is displayed for review and does not skip an otherwise valid order.
