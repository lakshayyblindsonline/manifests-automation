Check a whole list of order numbers.

Or install the browser extension

  1. Download the extension ZIP and extract it into a permanent folder.
  2. Open chrome://extensions or edge://extensions, then turn on Developer mode.
  3. Click Load unpacked and select the extracted Kiwi_Express_Order_Checker folder containing manifest.json.
  4. Click Kiwi Express Order Checker from the browser’s Extensions menu. You can open it from any tab.

The extension requests local progress storage and access to my.kiwiexpress.co.nz. It includes no remote scripts or analytics.

Run your list

  1. Paste one order per line, paste an Excel/Markdown table, or upload a CSV. For tables use an Order Ref heading. Customer Name is optional.
  2. Click Read list / reset results to preview your orders.
  3. Set the wait between requests (5–3600 seconds), then click Start / resume. The full original number, including suffixes, goes into /barcode/{order_number}.
  4. Keep the helper open. Click Copy table or Download CSV for all results.

FOUND: a matching order heading was returned. Any delivery status is accepted.
NO_RESPONSE: Kiwi’s normal tracking layout is empty, as in your second screenshot. Its default “dispatched” message does not count as a match.
REVIEW: a network error, different returned order, HTTP error, or unrecognised page. The batch pauses so you can check it.

Saved progress and waiting

Completed results save after every order. Start / resume skips FOUND and NO_RESPONSE rows and retries unfinished or review rows. Read list resets the results for a full recheck. Stop cancels an active request and keeps completed results. A closed or reloaded helper needs Start / resume to continue.

Your wait setting controls the normal pause. HTTP 429 triggers the server’s Retry-After plus a two-minute buffer, or an increasing fallback wait if no usable header is returned. That cooldown is saved and survives reopening. Stop interrupts the countdown; resuming honours the remaining cooldown. Bookmark and extension progress are stored separately.

CSV includes Order Ref, Customer Name, Result, Returned Order, Tracking No, Delivery Status, Receiver, Picked Up At, Delivered At, Details, Lookup URL and Checked At (UTC). Pickup and delivery dates retain the website’s wording and timezone.
