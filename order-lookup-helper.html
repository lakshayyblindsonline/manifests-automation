Global Trading · reusable daily order lookup

Look up your orders in Style Portal

Paste a different order list whenever you need it. This helper searches using Customer Reference, then creates an Excel-compatible CSV with Order Ref, Supplier Ref, Customer Name, Despatch.

Updating from an earlier version: replace your old bookmark with the button below once. Close any older helper panel before launching this version. Saved orders without Despatch information will be rechecked.

  1. Show your browser’s bookmarks bar (Ctrl + Shift + B in Chrome or Edge).
  2. Drag the blue Style order lookup button below onto the bookmarks bar. It is a bookmark that runs the helper.
  3. Return to the logged-in Manage Order page shown in your screenshots, then click your new bookmark.
  4. Paste today's order references or full report into the panel, click Load list / New run, and review the extracted references and names.
  5. Click Start / Resume. Keep that tab open until the searches finish.
  6. Click Download CSV. You can upload the CSV to our chat to present the completed table.

Style order lookup

Drag this button to the bookmarks bar; clicking it on this instruction page does not search orders. Open this file in your regular browser if the app preview cannot drag bookmarks.

The helper uses your existing Style Portal login and clicks Search in a separate page within the portal. It does not change orders. A timeout, login problem, or unfamiliar error stops the run and leaves that reference unchecked. Supplier Ref becomes NOT FOUND only when the portal explicitly names that reference in its no-order-found message.

Despatch information

The helper reads the Despatch column from the order's line table, as shown in your screenshot. It retains the displayed text. Blank cells, dashes, N/A values, or an absent Despatch column become NOT FOUND. If an order has multiple lines, distinct non-empty values are joined with ; . An order that is not found also has NOT FOUND in its Despatch column.

Daily input

Paste references separated by newlines, commas or spaces. You can also paste an Excel table, a CSV table, or a Markdown table with Order Ref and Customer Name headers. Two columns containing a reference and name are supported too. References are expected in the AU-number-two-letter format, with an optional numeric suffix such as -1.

Duplicate references are removed, preserving their first position. Loading any list starts a fresh run, including repeated references from a previous day. To continue an interrupted run, use Start / Resume without reloading the list.

Download completed results before loading a new list if you want to retain them. Names are taken from a labelled field in the portal when available, otherwise from your pasted table; if neither is available, the name stays blank. Only checked rows are exported. Progress is retained in this browser tab’s session. If the portal blocks the helper’s separate search page, the helper will stop and show a message.

If dragging the bookmark does not work

Click Copy helper code. On the logged-in Manage Order page, open your browser’s Developer Tools (F12 or Ctrl + Shift + J), select Console, paste the code and press Enter. If your browser prevents pasting, use the bookmark method or report the message in our chat.
