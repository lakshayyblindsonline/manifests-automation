Or install the Chrome / Edge extension

  1. Download the extension ZIP and extract it. The folder you select must contain manifest.json.
  2. Open chrome://extensions in Chrome or edge://extensions in Edge.
  3. Enable Developer mode, click Load unpacked, and select the extracted Hardback_Order_Lookup folder.
  4. Open Hardback Sales search, then click Hardback Order Lookup in the browser’s Extensions menu. Pin it for easier access.

The extension uses access granted when you click its button, browser scripting and local storage. It includes no external scripts or analytics.

Run a lookup

  1. Paste your table with headings, or upload a CSV. Accepted headings include Order Ref, Date Sent, Customer Name, Delivery Postcode, Order Status.
  2. Click Read table to check the order count and date range. The earliest and latest Date Sent apply to every search. Dates use day/month/year.
  3. Click Start lookup. The helper switches to All sales statuses, selects Within → Any Date, fills Search For, Start and End, and clicks Display for each order.
  4. Keep the helper and BUZ search tab open. Avoid manually navigating or searching the BUZ tab during the run.
  5. Click Copy table or Download CSV. Use Download lookup log for row-level explanations.

Results: NOT_FOUND means no exact match in the chosen date range. Multiple different Ref Nos. produce AMBIGUOUS. Unverified pages produce REVIEW. PENDING and STOPPED have not been completed. The lookup checks every returned results page before choosing a reference.

Pause and resume

Pause stops before the next automatic action. Stop keeps completed results. Reopening the helper restores its last saved table and results; use Retry unfinished / review rows to continue. Bookmark and extension progress are stored separately. Download results before moving to another browser or profile.

The helper submits searches and follows result pages. It does not open order editors or save order changes.
