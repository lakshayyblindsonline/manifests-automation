Run the batch

  1. Upload the CSV with Order Ref, Connote, ConnoteDate. The Direct Freight column names also work. A previous manual-review CSV is imported when no automatic batch exists.
  2. Choose the Supplier and Carrier for this batch, then click Start / resume batch — SAVE. All unfinished unique orders are processed in CSV order. Pause after the current order to change supplier or carrier before resuming.
  3. For products belonging to your selected supplier with a blank consignment number, it opens one eligible item-status link, sets Dispatched, chooses your selected carrier, ticks Do Not Send Dispatch Email To The Customer, fills that order’s Connote/date and selects only verified items from that supplier.
  4. It rechecks the fields and checkbox, records a Save intent, clicks Save Changes once, checks the returned values, reloads the same order and verifies persistence. Then it records SAVED_VERIFIED and advances.
  5. Keep both windows open. Pause after current order finishes/verifies that order before stopping. Download the results at any time.

Rows without an item status or without a supplier name are ignored. Only named, non-sample products from your selected supplier with a blank consignment number are eligible. Existing-consignment, sample and unnamed item checkboxes stay unticked. If every product for the selected supplier already has a consignment number, the order is skipped without opening an editor. Orders without the selected supplier, missing and already-dispatched matching orders are skipped. Identical duplicate CSV orders share one Save; conflicting duplicates require correction. Supplier references, confirmation dates and other suppliers are preserved.

Errors and resuming

Pre-Save row errors are marked REVIEW. When possible, the helper cancels only its own unsaved editor and continues. An uncertain Save pauses instead of submitting again. Use Retry REVIEW / verify earlier Save to check its persisted outcome; a previous Save is never repeated. Leave unverified Save for review lets you continue remaining rows after the editor is closed, while retaining its receipt.

Save-attempt records are kept separately for each order and supplier and survive reopening, clearing the list and new CSV uploads. Progress is saved per row to keep large lists responsive. All original rows, including duplicates, appear in the CSV report.
